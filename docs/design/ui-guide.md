# UI Guide

Guide UI compact pour conserver une direction visuelle coherente pendant le dev.

## Intentions

- Interface claire, lisible et rassurante
- Base Bootstrap legere, sans surcouche inutile
- Mise en avant des menus, des badges et des informations pratiques

## Palette

- Primary: `#1F5E3B`
- Secondary: `#C9A227`
- Dark: `#0F1411`
- Light: `#FFFFFF`
- Muted: `#7A8C7A`
- Background: `#FBF7F0`
- Text: `#131A15`

## Typographie

- Titres: `Montserrat`
- Texte courant: `Hind Madurai`
- Hierarchie cible:
  - `H1`: `40px / 700`
  - `H2`: `28px / 600`
  - corps: `16px`
  - small / liens secondaires: `14px`

## Composants a conserver

- Boutons `primary`, `outline` et `danger`
- Cartes menu
- Badges theme / regime
- Formulaires avec labels et erreurs visibles
- Alertes simples et lisibles

## Grille et espacement

- Grille Bootstrap 12 colonnes
- Echelle d'espacement: `8 / 16 / 24 / 32`
- Sections et cartes avec respirations verticales regulieres

## Accessibilite minimale

- Focus visible conserve
- Pas de placeholder seul en guise de label
- Contrastes lisibles sur les zones de texte
- Texte alternatif sur les images utiles
