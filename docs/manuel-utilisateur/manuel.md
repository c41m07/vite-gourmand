## 4. Parcours Visiteur
- Accéder à l’accueil
- Voir la liste des menus
- Utiliser les filtres (prix, thème, régime, min personnes)
- Voir le détail d’un menu
- Contacter l’entreprise

## 5. Parcours Utilisateur
- Créer un compte
- Se connecter / mot de passe oublié
- Commander un menu
- Voir ses commandes / suivi
- Annuler/modifier une commande si non “acceptée”
- Laisser un avis après commande terminée

## 6. Parcours Employé
- Gérer menus / plats / horaires
- Filtrer les commandes
- Mettre à jour les statuts
- Valider/refuser les avis

## 7. Parcours Admin
- Créer/désactiver des employés
- Accéder au dashboard stats (MongoDB)
