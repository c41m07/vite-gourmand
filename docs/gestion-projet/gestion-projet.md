## 2. Méthode
- Colonnes : Backlog / À faire / En cours / À relire-test / Terminé / Blocage

## 3. Organisation Git
- Branches : main / develop / feature/*
- Merge feature -> develop (après tests)
- Merge develop -> main (après stabilisation)

- Sprints suivants : dev + déploiement
